# Instagram Activity Analysis Using MySQL

## 1. Project Overview

This project focuses on analysing the Instagram activity and performance of a Tech Influencer account using **MySQL**.

The analysis explores content performance, audience engagement, profile visits, follower growth, and content-sharing patterns using SQL queries.

The objective is to answer business-oriented questions using structured data and identify meaningful insights that help understand the effectiveness of different Instagram content strategies.

## 2. Business Problem

Social media accounts publish different types of content to attract and engage their audiences. However, understanding which content performs better requires analysing engagement metrics and audience activity over time.

Without structured analysis, it becomes difficult to identify:

- Which post types generate higher impressions and reach?
- Which content categories receive more likes, comments, and saves?
- How do profile visits and follower growth vary across months?
- How does posting activity differ between weekends and weekdays?
- On which dates is follower growth the highest?
- Which content formats generate more shares?

This project uses SQL to investigate these questions and derive meaningful insights from Instagram activity data.

## 3. Project Objectives

- Analyse Instagram content performance across different post formats.
- Identify the most engaging content categories.
- Examine monthly profile visits and follower growth.
- Analyse weekend posting activity.
- Evaluate comments, likes, saves, shares, impressions, and reach.
- Identify dates with significant follower growth.
- Apply SQL concepts to solve practical business questions.

## 5. Dataset Description

The dataset covers Instagram activity from **January to September 2023**.

The analysis uses the following tables:

| Table Name | Description |
|---|---|
| `fact_content` | Contains Instagram content-related information and engagement metrics. |
| `fact_account` | Contains account-level metrics such as profile visits and new followers. |
| `dim_dates` | Contains date-related information used for time-based analysis. |

The project addresses the following 10 business questions using SQL.

## 7. SQL Concepts Used

The project applies the following SQL concepts:

- **SELECT and DISTINCT:** Retrieving relevant columns and unique values.
- **Aggregate Functions:** Using COUNT(), SUM(), MIN(), and MAX() to calculate metrics.
- **GROUP BY:** Grouping data by post type, category, and month.
- **ORDER BY:** Sorting results to identify high-performing categories and dates.
- **JOIN:** Combining relevant tables for analysis.
- **Date Functions:** Extracting month, date, and day-related information.
- **Common Table Expressions (CTEs):** Structuring complex queries.
- **Stored Procedures:** Performing reusable analysis for weekly content-sharing metrics.
